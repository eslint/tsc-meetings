### [feat: add `ecmaVersion: 2027`, fix globals](https://github.com/eslint/eslint/pull/21350)

**TSC Summary:** `ecmaVersion: 2026` currently enables Explicit Resource Management (syntax and globals) and Temporal (global), although the features are expected in the 2027 spec rather than the finalized 2026 spec. Explicit Resource Management syntax is also in the 2026 ESTree spec, and Acorn supports it with `ecmaVersion: 2026`.

* @nzakas preferred leaving the features in 2026, noting that users would not expect to be warned about either the syntax or `Temporal` when using that version.
* @fasttime and @mdjermanovic agreed that moving the features to 2027 would be a breaking change at this point.
* The TSC also discussed whether ESLint should wait until a feature is included in the yearly spec before accepting it, rather than accepting it when it reaches stage 4. @fasttime noted Acorn's policy of implementing features at stage 4. @nzakas said ESLint need not necessarily match ESTree and Acorn's policies.

**Resolution:** The TSC agreed to leave Explicit Resource Management and Temporal enabled in `ecmaVersion: 2026`. @mdjermanovic will open a separate issue to discuss the process for accepting new language features.
