### Bash Plugin

**TSC Summary:** @nzakas explained that the Bash plugin repo is currently private and the work has been split into several PRs that have only been code reviewed by AI. He proposed making the repo public, doing a sanity check, and publishing 0.1.0 to gather feedback from early users rather than perfecting everything before release.

* @mdjermanovic asked what 0.1.0 would include; @nzakas answered everything currently in the repo, as it is meant to be equivalent to ShellCheck.
* @fasttime finds reviewing AI-generated code tiresome: he mostly finds no bugs, but many small things that could be improved. @nzakas agreed and added that CodeRabbit is an excellent code reviewer and that he is confident in the rules thanks to `RuleTester`.
* @mdjermanovic confirmed the idea is to do quick reviews, get feedback, and then fix edge cases, ergonomic, or compatibility issues afterward; he agreed with that.
* @nzakas plans to dogfood the plugin on his personal `.sh` files. @fasttime offered to run it on his own `.sh` files to catch edge cases.
* @fasttime noted an existing plugin for linting `.sh` files, [`eslint-sh`](https://www.npmjs.com/package/eslint-sh); @nzakas linked [`@eslint-sh/eslint-plugin`](https://www.npmjs.com/package/@eslint-sh/eslint-plugin). @fasttime confirmed they are from the same author, who is not on GitHub.

**Resolution:** The TSC agreed to make the repo public, do a quick review of the existing PRs, and release 0.1.0 to get feedback.
